# CVAT fork

Форк хранит отфильтрованные исходники CVAT в `cvat/`, изменения отображения
прогресса задач и отдельные правила OPA для issues и комментариев организации.
Пользовательский образ собирается скриптом `build-ui.sh`; сервер использует
соответствующий релиз upstream с подключёнными правилами из `opa/rules/`.

Перед обновлением CVAT используйте:

- [Спецификацию изменений форка](docs/fork-specification.md): поведение, которое
  нужно сохранить, точки интеграции и сценарии приёмки.
- [Порядок обновления upstream](docs/upstream-upgrade.md): сравнение с исходным
  релизом, обновление subtree, перенос правил OPA и проверка результата.
- [Базовый снимок от 2026-11-13](docs/evidence/2026-11-13-fork-baseline.md):
  ревизии, полный список отличий внутри subtree и границы проверки.
- [Описание патча OPA](opa/README.md): подключение правил и существующие проверки.

[INFRA_MIGRATION.md](INFRA_MIGRATION.md) описывает отдельную незавершённую миграцию
инфраструктуры проверки. Имеющиеся Compose-скрипты нельзя считать её завершением.
